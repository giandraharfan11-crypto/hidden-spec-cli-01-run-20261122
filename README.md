mend is one command-line tool that applies AI-written edits in all four formats — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files, exactly to the written SPEC.md: it finds the lines each edit names even when whitespace or indentation drifted, and changes every file or none. Practice set: 100 of 100 checks pass. Matching runs in three tiers (exact, whitespace-tolerant, indentation-drifted) and every patch applies atomically: a patch that fails anywhere changes nothing.

## Run it

```sh
node main.ts [options] [PATCH]
```
